## Phase 0-1: Природа папки и структурная карта
Папка `TradeBotCS2_Demo` **не является репозиторием с исходным кодом**. 
Это скомпилированный билд для Windows (PyInstaller), который был распакован в Linux. 
- Наличие файлов: Внутри лежит `TradeBotCS2_Demo.exe` (~7.6 МБ) и папка с зависимостями `_internal`, которая распаковалась плоским списком (файлы имеют имена вида `TradeBotCS2_Demo\_internal\customtkinter\...`).
- Файлов исходного кода бота (`.py`) — **нет**. Все 150 найденных `.py` файлов относятся к сторонним библиотекам (`customtkinter`, `requests`, `cryptography`, `steamcom`), которые PyInstaller оставил в открытом виде или которые были так распакованы.
- Зависимости: `requirements.txt` отсутствует.
- Актуальность: Файлы датированы июлем 2026 года.

Согласно `README_DEMO.txt`, это ознакомительная "демо-версия", которая умеет сканировать CSFloat, Market.CSGO, Waxpeer, ShadowPay, имеет GUI на Tkinter, но в ней аппаратно отключены POST-запросы на торговлю.

## Phase 2: Архитектурное сравнение
Из-за отсутствия исходного кода прямое сравнение архитектуры (наличие `asyncio`, обработка `trade_protected`, `rate_limit`) невозможно. 
Отличия в функционале (согласно README):
- Бот является мультиплатформенным (в отличие от нашего, который работает только с DMarket).
- Бот имеет десктопный GUI (CustomTkinter).
- Поддерживает фильтры по износу (wear) и StatTrak.

## Phase 3: Качество кода
Единственный код, доступный для анализа — это бандлированные сторонние библиотеки. Для проверки был проанализирован файл `steamcom/client.py`:
- `radon cc`: Показал цикломатическую сложность до B(6), в среднем A.
- `vulture`: Нашел неиспользуемые импорты.
- Найдено 23 `TODO/FIXME` по всем `.py` библиотекам в папке.
Поскольку это не код самого бота, эти метрики относятся к качеству open-source библиотек.
