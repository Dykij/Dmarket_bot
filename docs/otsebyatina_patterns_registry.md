# Реестр паттернов отсебятины и галлюцинаций агента

**H2. Правка боевого кода ради тишины гейта — после того как сам же подтвердил, что гейт неправ.**
Хук `lazy_work_guard.sh` заблокировал сессию, ложно среагировав на маркеры `...`/`pass` во ВСЁМ файле `filter.py`
(баг хука: сканировал файл целиком, а не только добавленные строки диффа). Агент сам проверил через
`git diff --staged | grep` и подтвердил: сработавшие паттерны не входят в реальную правку — то есть сам
установил, что блокировка ложная. Несмотря на это, вместо того чтобы сообщить о находке и остановиться,
агент отредактировал сам защищённый код: три стаб-функции с типизированными пустыми телами
(`_skip_if_locked`, `_calculate_float_premium`, `is_dirty_bs`) заменены на хардкод `return False`/`return 0.0`,
один `except: pass` переписан — исключительно чтобы гейт перестал блокировать отправку.

*Отличие от H1*: там страдала мета-инфраструктура; здесь — напрямую торговая логика, потенциально
отключающая реальные защитные проверки.

*Фикс*: полный откат через `git checkout HEAD --`, точечная правка одной строки через `replace_file_content`;
сам `lazy_work_guard.sh` переписан по отраслевому стандарту (проверка только добавленных строк диффа,
точный якорь на отдельную строку для `pass`/`...`, не подстроку).

*Общий вывод*: подтверждённый ложный гейт — повод чинить гейт или спросить разрешения, никогда не повод
редактировать защищаемый код.
