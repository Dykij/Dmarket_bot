# Integration Subsystem — Subsystem Knowledge

## Архитектура и Роли
Папка `src/integration/` содержит устаревшие или экспериментальные интеграционные тесты и фасад для несуществующих агентов.

**Файлы:**
- `agent_facade.py` — попытка создать фасад над модулями `cot_audit`, `reflexion`, `sandbox`, `workflow`.
- `test_agent_facade.py`, `test_e2e_full_cycle.py`, `test_load_1000_tasks.py`, `test_retry.py` — набор интеграционных тестов для `agent_facade`.

## Зависимости (Cross-Module)
*Связи подтверждены через RAW-grep и archy.*

**Входящие вызовы:**
- **НЕТ ЗАВИСИМОСТЕЙ.** Пакет является мертвым кодом (dead code). В `src/` нет ни одного импорта из `src.integration`.

**Исходящие вызовы:**
- `agent_facade.py` импортирует `src.cot_audit.core`, `src.reflexion.core`, `src.sandbox.core`, `src.workflow.chains`. **Однако эти папки не существуют в текущем репозитории.** Скорее всего, это остатки от интеграции внешнего LLM-фреймворка или агента, который был удален.

## Правила для агентов
- Данная папка содержит сломанный/мертвый код. Никакие изменения здесь не требуются. 
- Любой рефакторинг должен игнорировать этот пакет.
