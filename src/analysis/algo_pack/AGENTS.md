# Algo Pack — Subsystem Knowledge

## Архитектура и Роли
Папка `src/analysis/algo_pack/` содержит набор независимых математических, статистических и количественных (quant) алгоритмов для анализа рынка и управления позициями. 
Здесь нет бизнес-логики бота — только чистая математика. Каждый модуль самодостаточен и реализует конкретную модель.

**Основные алгоритмы:**
- `__init__.py` — Инициализация пакета. Содержит метаданные об источниках алгоритмов (CP-Algorithms, arXiv, Habr, GeeksforGeeks), адаптированных для стратегии мгновенной перепродажи DMarket.
- `bayesian_stats.py` — Байесовская статистика (оценка win rate, Beta-распределения).
- `event_driven.py` — Событийно-ориентированные вычисления.
- `ewma.py` — Экспоненциально взвешенное скользящее среднее (EWMA) и волатильность.
- `garch.py` — Модель GARCH (Generalized Autoregressive Conditional Heteroskedasticity) для прогнозирования волатильности.
- `hawkes.py` — Процессы Хоукса (Hawkes processes) для моделирования кластеризации сделок.
- `hmm_regime.py` — Скрытые марковские модели (Hidden Markov Models) для определения режимов рынка.
- `info_theory.py` — Метрики теории информации (энтропия и др.).
- `ou_process.py` — Процесс Орнштейна-Уленбека для mean-reverting стратегий.
- `regime_detector.py` — Определение текущего режима рынка (тренд, флэт, высокая волатильность).
- `sell_optimizer.py` — Оптимизация цен продажи.
- `sliding_window.py` — Вычисления в скользящем окне.
- `thompson_sampling.py` — Сэмплирование Томпсона (для балансировки exploration/exploitation).
- `trend_strength.py` — Оценка силы тренда (ADX и т.д.).
- `vpin.py` — Индикатор токсичности потока ордеров VPIN (Volume-Synchronized Probability of Informed Trading).

## Зависимости (Cross-Module)
*Данные подтверждены через RAW-grep и archy.*

**Входящие вызовы (Кто использует `algo_pack`):**
- Подсистема `src/core/target_sniping/` активно импортирует эти модели, часто локально внутри функций:
  - `position_guard.py` (импорт `ewma`)
  - `microstructure_pipeline.py` (импорты `hawkes`, `ewma`, `regime_detector`, `hmm_regime`)
  - `filter.py` (импорты `bayesian_stats`, `ewma`)
  - `ranking.py` (импорты `regime_detector`, `trend_strength`)

**Исходящие вызовы (От чего зависит `algo_pack`):**
- **Отсутствуют внутренние зависимости от других частей `src/` (ЗА ИСКЛЮЧЕНИЕМ нарушения: `ou_process.py` и `event_driven.py` импортируют `Config` из `src.config`, что нарушает правило pure functions!).** Это чистая библиотека. Модули используют только внешние библиотеки (numpy, scipy и т.д.).
- *Примечание по archy: Внутри `algo_pack` модули также полностью независимы друг от друга (нет внутренних импортов).*
