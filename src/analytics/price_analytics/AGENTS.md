# Price Analytics Subsystem — Subsystem Knowledge

## Архитектура и Роли
Папка `src/analytics/price_analytics/` содержит полностью изолированный математический движок для глубокого анализа цен, трендов и ликвидности предметов. Пакет не имеет исходящих зависимостей на другие модули приложения и функционирует как чистая библиотека.

**Ядро аналитики:**
- `core.py` — центральный процессор, агрегирующий вычисления (вызывает индикаторы, ликвидность и тренды).
- `__init__.py` — реэкспорт интерфейсов для внешнего использования.

**Модели и Данные:**
- `models.py` — дата-классы и Pydantic-модели для аналитических данных (используются повсеместно внутри подпапки).
- `enums.py` — перечисления для состояний рынка (TrendDirection, LiquidityLevel и т.д.).

**Математика и Расчеты:**
- `indicators.py` — расчет математических индикаторов (RSI, скользящие средние SMA/EMA, волатильность).
- `trends.py` — детекция трендов на основе индикаторов (рост, падение, флэт).
- `liquidity.py` — оценка ликвидности предмета (как быстро его можно продать).

## Зависимости (Cross-Module)
*Связи подтверждены через RAW-grep и archy.*

**Входящие вызовы (Кто использует `price_analytics`):**
- **Главный фасад:** `src/analytics/price_analytics.py` (реэкспортирует этот пакет для более удобного доступа снаружи).
- **Item Intel:** `src/core/item_intel.py` (использует аналитику для принятия решений о покупке).

**Исходящие вызовы (От чего зависит `price_analytics`):**
- Пакет **полностью независим**. Нет ни одного импорта из `src.*` (кроме внутренних импортов внутри самого пакета).
- *Внутренняя структура (archy):* Высокая связность. `core.py` импортирует `indicators`, `liquidity`, `models`, `trends`. Все они, в свою очередь, зависят от базовых дата-структур в `models.py` и `enums.py`.

## Правила для агентов
- **Strictly pure functions:** Модули в этой папке не должны делать сетевых запросов, не должны обращаться к БД и не должны читать глобальный `Config`. Все нужные данные (история цен, настройки периода) должны передаваться в функции как аргументы.
- **Dependency Isolation:** Запрещено добавлять импорты из других частей бота в этот модуль. Это чистая библиотека.
