# Analytics Subsystem — Subsystem Knowledge

## Архитектура и Роли
Папка `src/analytics/` является корневой для всех аналитических расчетов бота, включая оценку прибыльности, календари событий, отслеживание филлеров и наклеек, а также выступает точкой входа для вложенных аналитических подсистем.

**Модули верхнего уровня:**
- `event_calendar.py` — календарь игровых событий (например, турниры CS2), влияющих на волатильность цен.
- `self_reflection.py` — модуль самоанализа профита бота (расчет реального P&L на основе истории покупок/продаж).
- `stickers_evaluator.py` — оценка стоимости наклеек (stickers) на оружии CS2, расчет переплаты за редкие стикеры.
- `filler_tracker.py` — отслеживание и аналитика предметов-филлеров.

**Фасадные файлы (точки входа для подмодулей):**
- `backtester.py` — фасад для подмодуля `src/analytics/backtester/`.
- `price_analytics.py` — фасад для подмодуля `src/analytics/price_analytics/`.
- `historical_data.py` — фасад для подмодуля `src/analytics/historical_data/`.
- `__init__.py` — реэкспорт.

*(Вложенные подсистемы описаны в их собственных `AGENTS.md` в соответствующих подпапках).*

## Зависимости (Cross-Module)
*Связи подтверждены через RAW-grep и archy.*

**Входящие вызовы (Кто использует `analytics` корневой уровень):**
- **Trading Core:** `src/core/target_sniping/core.py`, `filter.py`, `ranking.py`.
- **Resale / Scanners:** `src/core/resale_pipeline.py`, `src/core/item_intel.py`.
- **Telegram Bot (UI):** `src/telegram/control_bot/commands/views.py`, `callbacks.py`.
- **Strategies:** `src/strategies/market_maker.py`.

**Исходящие вызовы (От чего зависит `analytics`):**
- `src.config` (глобальная конфигурация).
- `src.db.price_history` (получение исторических данных для анализа).
- *Внутренняя структура (archy):* В корне папки файлы практически не зависят друг от друга, выполняя изолированные аналитические задачи (однако фасадные файлы и `__init__.py` пробрасывают зависимости во вложенные подсистемы).

## Правила для агентов
- Модули в `src/analytics/` должны быть read-only по отношению к БД (только чтение `price_db`), за исключением `self_reflection.py`, который может обновлять агрегированную статистику, и специализированных коллекторов.
- Вся сложная математика для определения трендов или бэктестинга вынесена во вложенные пакеты. Корневые модули решают прикладные задачи бота (события, стикеры).
