# mock_orderbook_generator

Этот скилл генерирует моки (synthetic data) для стакана.
Он не выполняет сетевых вызовов.
Применяется для генерации тестовых наборов (например, предметы с разным флоатом, паттерном, трейд-локом) для покрытия unit-тестов сортировки и поиска арбитражных окон.
