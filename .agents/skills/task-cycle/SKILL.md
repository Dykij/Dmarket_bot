# Workflow: /task-cycle

1. **Опубликовать прямо в чат** (не только в Plan Artifact) три раздела:
   - **Implementation Plan** — подход, какие файлы затронуты, риски.
   - **Walkthrough** — пошагово что и почему будет сделано.
   - **Task** — явный чек-лист пунктов, каждый пункт с номером.
2. ДОЖДАТЬСЯ явного Approve от пользователя на Task в чате. До получения подтверждения ничего не менять!
3. Диспетчеризовать релевантных субагентов под конкретные пункты Task (с учётом контрактов из AGENTS.md).
4. Выполнять строго по пунктам Task. Любое отклонение от списка — не молча, а отдельной пометкой "SCOPE CREEP" в чате (зона ответственности scope-auditor).
5. После каждого значимого шага — RAW-вывод в чат (полный, не сокращённый пересказ), даже если он длинный.
6. В конце — сводка двумя колонками: "подтверждено RAW-данными" | "не подтверждено, требует проверки".
