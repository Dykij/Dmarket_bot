# Корреляционный анализ предметов CS2

Анализ кросс-корреляции (взаимосвязей) между различными предметами (скинами, кейсами, наклейками) в экосистеме DMarket/CS2. Используется для диверсификации инвентаря, управления рисками и поиска аномалий для парного трейдинга (pairs trading).

## Почему корреляция важна на рынке CS2

- **Диверсификация**: Владение множеством скинов из одной коллекции или одного типа оружия (например, 10 разных AK-47) не дает реальной диверсификации, так как их цены движутся синхронно.
- **Риск-менеджмент**: Общий риск портфеля зависит от ковариации активов. Падение популярности M4A1-S затронет все скины на это оружие.

## Методы оценки корреляции

### Pearson vs Spearman

- **Pearson**: Линейная зависимость (всегда считать на лог-доходностях, а не на ценах).
- **Spearman Rank**: Ранговая корреляция (лучше подходит для нелинейных рынков CS2 с резкими скачками цен).

```python
import pandas as pd

# Всегда используйте доходности для расчетов, не абсолютные цены!
returns_ak47 = df_ak47['price'].pct_change().dropna()
returns_m4a4 = df_m4a4['price'].pct_change().dropna()

# Ранговая корреляция Спирмена (устойчива к выбросам)
corr = returns_ak47.corr(returns_m4a4, method='spearman')
```

## Паттерны корреляции, специфичные для CS2

1. **Внутри категорий (Weapon Type)**: Высокая корреляция (>0.8) между скинами на одно и то же метовое оружие (AK-47, AWP). Если оружие нерфят в патче, падают все его скины.
2. **Взаимозаменяемое оружие (Substitutes)**: Исторически наблюдается отрицательная корреляция между M4A1-S и M4A4. Бафф одного приводит к росту его скинов и падению скинов другого.
3. **Коллекции и операции**: Предметы из одной коллекции (особенно снятые с дропа) имеют тенденцию расти синхронно (корреляция >0.9).
4. **Кейсы vs Ключи**: Экономика жестко привязана к стоимости ключей (фиксирована Valve) и ожидаемой стоимости распаковки кейсов (Expected Value).
5. **Флоат (Wear)**: Factory New (FN) и Minimal Wear (MW) версии одного и того же скина имеют околоидеальную корреляцию (>0.95), если не происходит манипуляций с контрактами обмена.
