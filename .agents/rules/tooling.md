# Tooling Directives

- Для структурного поиска по коду — **ast-grep**, НЕ plain-text grep, если не попросили явно.
- Для правок Python сложнее однострочной замены — ТОЛЬКО **libcst**, никогда `sed`/`re.sub`/самодельные `.replace()`-скрипты.
- Перед коммитом любой правки — **difftastic**-сравнение на предмет семантически пустого диффа.
- Для быстрого текстового поиска по большим директориям — **tgrep** (с построенным индексом), не голый `grep`.
- При подозрении на "отсебятину" — сверяться с реестром паттернов H1-H17: см. `.agents/rules/otsebyatina-registry.md`.
